Gromazeef Database Setup

Ye checklist hai. Supabase mein tables manually ya SQL Editor se create karni hongi.

  • profiles — id, username, full_name, bio, updated_at
  • posts — id, user_id, caption, media_url, media_type, created_at
  • follows — follower_id, following_id
  • Storage bucket — gromazeef-media

Har table par Row Level Security (RLS) enable karo aur policies set karo. Public users ko bina permission private data read ya modify karne ki access mat dena.

Check abhi run nahi hua.
