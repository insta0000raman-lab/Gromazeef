# 🌐 GROMAZEEF

### Connect • Share • Discover

Welcome to **Gromazeef**, a social platform project designed to bring people together through posts, profiles, and community interactions.

## ✨ Features

- 👤 User authentication
- 📝 Create and share posts
- ❤️ Like and save posts
- 💬 Comments
- 🔍 Explore posts
- 👥 User profiles and follow system
- 🔔 Notifications
- ✉️ Messaging section
- ⚙️ Account settings
- 📱 Responsive interface for mobile and desktop

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Supabase

## ⚙️ Setup

1. Clone or download this repository.
2. Open `index.html`.
3. Configure your Supabase project URL and public anon/publishable key.
4. Create the required database tables and configure Row Level Security policies.
5. Deploy using GitHub Pages.

## 🔐 Security

Never publish your Supabase `service_role` key, passwords, or other private credentials.

## 📌 Project Status

Gromazeef is under development. Some features require additional database configuration before they can work.
